# ai-training

A training repo for learning how to add AI features to a web app. Each app here is a small working example of an AI assistant that can read and change the app's data through tools.

## Apps

- [`todo/`](todo/README.md): a Next.js todo list with an embedded CopilotKit chat that can read and change the list.

## Getting started

```bash
cd todo
pnpm install
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000). See [`todo/README.md`](todo/README.md) for the environment variables the chat needs.
